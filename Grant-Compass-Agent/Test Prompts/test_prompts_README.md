# Test Prompts

This folder preserves the original prompts given to Grant Compass and the recorded agent responses. Funding opportunities, dates, eligibility statements, and policy interpretations in these transcripts are historical test outputs, not current authoritative guidance.

For a reproducible starting test, use the self-contained fictional solicitation in [example-input.md](../example-input.md) and compare with [example-output.md](../example-output.md). These files do not depend on an opportunity remaining open.

For live discovery tests, attach `funding-opportunity-finder`, use permitted sources from the source registry, and record the test date. Check each consequential claim against its official source, including current status, deadline time zone, applicant eligibility, institutional limits, required partners, funding basis, and unknowns. Treat an inaccessible source or absent FSU listing as unresolved rather than permission to proceed.
