# Grant Compass Output Templates

## General response rules

For every consequential response:

- Put submission-blocking issues first.
- Distinguish sponsor requirements, FSU requirements, and recommendations.
- Cite or identify the current official source for deadlines, eligibility, application limits, funding limits, page limits, required components, cost sharing, and review criteria.
- Do not infer missing requirements.
- Use the phrase **Not identified in the available authoritative sources** when a consequential fact cannot be established.
- End with the recommended next three actions.
- Use concise, faculty-oriented language.

Use one of these labels when helpful:

- **Confirmed requirement**
- **Apparent concern**
- **Recommendation**
- **Unknown or unresolved**
