# Grant Compass Approved Source Registry

## Purpose

Use this registry to control which websites and other knowledge sources Grant Compass may use. A source should not be treated as production-ready until its URL, retrieval behavior, content scope, and output citations have been tested in ArtesAI.

This registry documents approval to retrieve information. It does not make every statement on a source controlling. For a specific opportunity, the current solicitation and controlling amendment remain the highest-authority sources.

## Source use rules

1. Use official sponsor and FSU sources for consequential requirements.
2. Treat discovery databases and search results as leads until the official source is opened.
3. Record the retrieval or verification date.
4. Distinguish current pages from archived or superseded pages.
5. Remove or conditionally approve sources that ArtesAI cannot retrieve reliably.
6. Do not store credentials, tokens, passwords, or confidential API details in this file.
7. Review this registry monthly during the pilot and quarterly after stabilization.

## Status values

- **Approved** - tested and reliable for its stated purpose.
- **Conditional** - useful with a documented limitation or required human verification.
- **Testing** - not yet approved for faculty-facing use.
- **Removed** - do not use.

## Website acceptance test

Before changing a source from Testing to Approved, verify:

- [ ] ArtesAI opens the intended URL.
- [ ] ArtesAI retrieves the relevant page text.
- [ ] ArtesAI follows links needed for the source's stated purpose.
- [ ] ArtesAI can read linked solicitation PDFs when necessary.
- [ ] ArtesAI distinguishes current and archived pages.
- [ ] ArtesAI reports the official URL in its answer.
- [ ] ArtesAI identifies source dates or versions when available.
- [ ] ArtesAI does not rely only on a search snippet.
- [ ] The configured maximum-page value captures the relevant content without excessive unrelated material.
- [ ] A known failure produces an unresolved label rather than an invented answer.
