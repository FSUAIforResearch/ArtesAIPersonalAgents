# Grant Compass Output Templates

## Why Grant Compass Uses This Knowledge

Consistent formats help researchers compare opportunities and act on the results. Use the format for the selected skill instead of repeating every template in every response. Populate fields only from available evidence. A template field does not establish that a sponsor requires a document or that an FSU process applies.

## Rules for All Formats

- Put submission blockers first.
- Separate **Sponsor Required**, **FSU Required**, and **Recommended Practice**.
- Support consequential claims with source title, official URL when available, section or page, version, and actual verification date. An uploaded file's analysis date is not a live verification date.
- Preserve deadline time and original time zone.
- Label unsupported facts **Unknown or Unresolved**. Use **Not identified in the available authoritative sources** where applicable.
- Identify fictional examples as exercise evidence, with no invented official URL or live verification.
- Put the source list before the final **Recommended Next Three Actions**.

## Funding Search Results — Finder

Start with the research profile, search date, actual search sources, and scope limitations. Return 3–8 verified candidates by default when supported; do not pad the list to reach a target count.

| Field for each candidate | Include |
| :--- | :--- |
| Identity and status | Sponsor, program, opportunity number, current status. |
| Timing | Deadline with time zone, mandatory LOI or preapplication. |
| Scale | Award basis and ceiling or range, project duration. |
| Fit | Qualitative classification, 2–4 reasons, mismatches and eligibility concerns. |
| FSU implications | Institutional limit, internal-process status, next referral. |
| Evidence | Official source, version when available, verification date, unresolved facts. |

Separate **Unverified Leads** from recommended current opportunities. Do not claim that the search is exhaustive.

## Opportunity Brief — Verifier

Use these sections:

1. **Submission-Blocking Issues:** Closed status, missed mandatory dates, limits, eligibility conflicts, required partners, cost share, or system barriers.
2. **Critical Dates:** Sponsor deadline, LOI, preapplication, other mandatory milestones, and internal date or reason it cannot be calculated.
3. **Opportunity Summary:** Sponsor, program, identifier, scope, version, status, amendments and instructions reviewed.
4. **Eligibility and Application Limits:** Institution and PI conditions; institutional and investigator limits separately.
5. **Funding and Project Period:** Total/direct-cost basis, ceiling or range, duration, cost share, F&A restrictions if stated.
6. **Components and Attachments:** Required, conditional, and optional documents separately; limits and formatting tied to each component.
7. **Review and Submission:** Published criteria and weights, submission system, registrations, authorized submitter.
8. **FSU Routing and Review Flags:** Current-source-supported institutional requirements and possible compliance referrals.
9. **Unknowns, Sources, and Next Three Actions.**

## Research Match — Matcher

Give one qualitative classification with its uncertainty caution. Explain alignment and mismatches, eligibility concerns, team and mechanism fit, blockers, and missing facts.

| Published criterion | Project evidence or proposed content | Development or verification needed |
| :--- | :--- | :--- |
| Use the sponsor's actual criterion. | Use supplied project facts. | Identify the missing evidence or decision. |

## Limited-Submission Check — Checker

Report the sponsor's exact limit, source location, submission type, and organizational unit. Separate institutional and investigator limits. Report one supported status:

- **Yes — FSU internal process identified.**
- **Sponsor limit identified — no current FSU listing found.**
- **Possibly limited — institutional interpretation required.**
- **Investigator limit only.**
- **No explicit institutional limit identified.**
- **Unable to verify.**

Include any verified FSU internal deadline and selection materials. Do not say no listing was found if no search was performed. An absent listing is not permission to proceed. Refer unresolved institutional limits to Research Development.

## Proposal Checklist and Timeline — Planner

State the planning basis: verified opportunity, source version, sponsor deadline/time zone, FSU lead/subrecipient role, current project stage, and internal-date status. Put blockers first. Create three separate checklists for **Sponsor Required**, **FSU Required**, and **Recommended Practice**. Add only supported requirements; leave current FSU requirements unresolved when authoritative evidence is unavailable.

| Target date or relative milestone | Task | Category | Responsible role | Dependency | Status |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Use a supported date or clearly recommended relative target. | Describe a concrete action. | Sponsor Required / FSU Required / Recommended Practice. | Use a role unless a name is supplied. | Identify what must happen first. | Use supplied status or mark unresolved. |

Calculate tentative internal dates only with the current policy, closures, exact sponsor deadline, applicant role, and applicable pass-through timing. Otherwise use relative milestones. Recommended buffers are not FSU policy.

## Routing Response

Give the funding source and flow, apparent routing office, evidence, uncertainty, and verification needed. For each possible compliance review, identify the project trigger and responsible referral. State that the agent is flagging a possible review need, not deciding compliance or approval.

## Sponsor-Aligned Outline — Outliner

Preserve mandatory section titles and order. For each section, state the verified requirement, source, component-specific limit, review criteria addressed, suggested content, and missing project evidence. Label suggested page allocations as recommendations and ensure their sum respects the combined limit.

| Published review criterion | Required proposal section(s) | Evidence or content needed |
| :--- | :--- | :--- |
| Use the sponsor's actual criterion and weight if stated. | Preserve its section title. | Identify supplied evidence or a factual gap. |

List required and conditional attachments separately. Do not manufacture preliminary data, citations, personnel, facilities, partners, commitments, budgets, or approvals. Use explicit placeholders in drafts, for example **[PLACEHOLDER: Confirm partner role and signed commitment.]** The result is a drafting aid, not a submission-ready application.
