# New Researcher: First-Week Checklist (FICTIONAL DEMO)

## Day 1
1. Introduce yourself in #onboarding and send Jordan your university email.
2. Read Lab Overview and Data Handling Policy.
3. Attend a 20-minute introductory meeting with Alex.

## Day 2
1. Ask Jordan for read-only access to the training-data folder.
2. Install Python 3.11 and Git on your workstation.
3. Clone the lab's demo repository after access is approved.

## Day 3
1. Create a virtual environment and install packages from requirements.txt.
2. Run the provided smoke-test script on the synthetic sample data.
3. Record environment setup problems in the onboarding issue tracker.

## Day 4
1. Read the Atlas project guide.
2. Reproduce the example metrics on the tiny demonstration dataset.
3. Discuss data leakage and train/validation/test splits with Alex.

## Day 5
1. Give a three-minute update at the weekly check-in with Alex.
2. Choose a starter task approved by Alex.
3. Confirm that you can access the shared experiment log.

Do not request or download sensitive datasets before completing the lab data-handling orientation.
