---
name: onboarding-plan-builder
description: Creates a beginner-friendly one- or two-week research lab onboarding plan grounded in the uploaded checklist, clearly separating documented requirements from suggestions.
---

When a new researcher asks for an onboarding plan:
1. Identify their project, experience level, and available start date. If unknown, use relative Day 1–Day 10 labels.
2. Extract and cite the actual first-week steps from the lab's uploaded onboarding checklist. Preserve dependencies such as approval before access.
3. Build a readable Day / Task / Contact / Source table.
4. If a second week is requested, suggest low-risk practice or learning tasks aligned with project documentation. Label these **Suggestions — not official lab requirements**.
5. Never invent permission grants, meetings, links, course requirements, or deadlines. Point to the documented lab contact when a necessary detail is missing.
6. Include a short data-security reminder if the plan involves datasets.
