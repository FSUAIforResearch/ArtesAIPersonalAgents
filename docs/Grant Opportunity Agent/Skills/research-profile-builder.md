# Research Profile Builder

Create a concise, search-ready funding profile using the minimum non-confidential information necessary.

## Minimum Input

Require only:

1. A short research description.
2. What the faculty member wants the funding to support.

Do not require a CV, biosketch, abstract, budget, proposal, or dataset. Accept these only as optional context.

## Data Minimization

Never require raw data, participant information, student records, protected health information, proprietary datasets, confidential partner information, export-controlled material, or sponsor-restricted information.

Do not place sensitive or confidential details into web searches. If sensitive details are provided, generalize them before creating search terms.

## Workflow

1. Extract only information supported by the faculty member's description or provided materials.
2. Identify the primary research topic and what the requested funding would support.
3. Identify relevant disciplines, themes, methods, populations, systems, geographic areas, or applications when stated.
4. Separate information explicitly provided by the faculty member from suggested search terminology.
5. Generate sponsor-friendly search terms without changing the underlying research.
6. Ask no more than three follow-up questions, and only when the answers would materially improve the funding search.
7. If optional details remain unknown, proceed and label them as unknown rather than blocking the search.

## Optional Information

Use the following when provided, but do not require them:

- Field or discipline
- Career stage
- Project stage
- Funding target
- Deadline window
- Preferred sponsor
- Geographic focus
- Collaboration needs
- Project abstract
- CV or biosketch

## Output

Create a structured profile containing:

- Research summary
- What the funding should support
- Primary disciplines
- Research themes
- Methods or capabilities, if stated
- Population, system, geography, or application, if relevant
- Project stage, if stated
- Career stage, if stated
- Funding target, if stated
- Deadline window, if stated
- Collaboration needs, if stated
- Eligibility facts that may require confirmation
- Six to twelve concise search phrases

## Search Phrase Rules

Search phrases should:

- Preserve the faculty member's actual research focus.
- Include common sponsor terminology when useful.
- Be concise enough for effective web searching.
- Cover multiple reasonable ways a sponsor might describe the research area.
- Avoid sensitive or confidential project details.

Do not invent expertise, credentials, institutional resources, partnerships, preliminary results, career stage, or eligibility information.

Do not claim that the faculty member is eligible for a funding program. Eligibility must be evaluated separately against the current official grant requirements.
