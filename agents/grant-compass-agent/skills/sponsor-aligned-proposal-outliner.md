# Sponsor-Aligned Proposal Outliner (`/outline-proposal`)

## When to Apply This Skill

Apply when the user types `/outline-proposal` or asks for a proposal outline, writing plan, page allocation, or review-criteria crosswalk for a verified funding opportunity. Follow the workflow below and end with three prioritized next actions.

## Objective

Create an editable, section-by-section **Proposal Outline** and **Review-Criteria Crosswalk** that mirrors the sponsor's exact required structure and formatting limits while using explicit `[PLACEHOLDER: ...]` markers for any project evidence, citations, or commitments the researcher has not yet supplied.

## Core Outlining Guardrails

1. **Preserve Mandatory Sponsor Structure**: Use the sponsor's exact required narrative section titles and order. Never invent required sections or apply one component's page limit to the whole application.
2. **Recommended Page Allocations**: When the sponsor sets one combined page limit across multiple narrative sections without per-section caps, propose a breakdown weighted by the published review criteria and label it **Recommended page allocation** (not a sponsor requirement).
3. **Zero Fabricated Evidence (Use `[PLACEHOLDER]` Markers)**:
   - Populate sections only with project facts supplied by the user.
   - Never invent preliminary data, sensor/survey results, literature citations, collaborator names, partner commitments, facilities, or institutional approvals.
   - Insert bold bracketed placeholders where researcher input is needed, such as:
     - `**[PLACEHOLDER: Insert verified evidence of local need and peer-reviewed citations.]**`
     - `**[PLACEHOLDER: Confirm partner responsibilities, resources, and signed commitment letter.]**`
     - `**[PLACEHOLDER: Specify sample selection, measurement schedule, and analysis plan.]**`

## Step-by-Step Workflow

1. **Confirm Source Control & Page Budget**: State the sponsor, program, opportunity number, combined or per-section page/word limits, formatting rules (font size, margins, file type), and **Recommended page allocation** (when only a combined limit is given).
2. **Draft the Section-by-Section Editable Outline**:
   For each required narrative section (using the sponsor's exact heading and order), include:
   - **Sponsor requirement**: Verified rule and source section/page.
   - **Review criterion**: The published evaluation criterion (and weight, if stated) addressed in this section.
   - **Content & supplied project facts**: How the user's stated aims, methods, population, and team fit here (distinguishing confirmed facts from expressions of interest or exploratory work).
   - **Placeholders**: 2–3 specific `**[PLACEHOLDER: ...]**` prompts for missing evidence, citations, methods detail, or partner confirmations.
3. **List Required Attachments & Build the Review-Criteria Crosswalk**:
   - Summarize separate required attachments (references, budget/justification, biosketches/CVs, partner letters, data plans) with their page limits.
   - Provide a **Review-Criteria Crosswalk** table with these exact columns:
     `Published Criterion | Weight | Primary Section | Evidence to Develop`
4. **End with Sources & Recommended Next Three Actions**: Remind the user that eligibility, institutional selection, budget review, and compliance remain with the responsible FSU offices, and provide **three prioritized next actions**.
