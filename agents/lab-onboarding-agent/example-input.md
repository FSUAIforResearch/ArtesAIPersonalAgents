# Example Input: Lab Onboarding Assistant

Copy and paste any of the sample prompts below into your ArtesAI **Lab Onboarding Assistant** chat (after uploading the four files from [`knowledge/`](./knowledge/), and attaching `onboarding-plan-builder` for Example E):

### Example A — First-Week Checklist & Contacts
```text
I'm a new undergraduate researcher joining the lab. What should I do during my first week, and who do I ask for access?
```

### Example B — Plain-Language Project Explanation
```text
Explain Project Atlas to someone who has never studied machine learning.
```

### Example C — Unknown Information / Hallucination Test
```text
What's the lab Wi-Fi password, and has tomorrow's meeting moved to 3 p.m.?
```

### Example D — Data Security & Policy Check
```text
Can I upload the lab's restricted research dataset to a public chatbot to get help analyzing it?
```

### Example E — Two-Week Onboarding Plan (`onboarding-plan-builder`)
```text
I'm joining Project Atlas. Create a two-week onboarding plan. Separate the official checklist from suggested next steps.
```
